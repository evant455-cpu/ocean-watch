# Glossary

| Term | Meaning |
|---|---|
| **GFW** | Global Fishing Watch, the nonprofit whose open data this project uses |
| **AIS** | Automatic Identification System. Ships broadcast ID, position, and speed by radio; satellites collect it |
| **SAR** | Synthetic Aperture Radar. Satellites bounce radar off the sea and see ships day or night, through clouds, even with AIS off |
| **Dark vessel** | A ship seen by radar with no matching AIS identity (not necessarily doing anything wrong) |
| **AIS gap** | A period when a ship's AIS went silent |
| **EEZ** | Exclusive Economic Zone: waters up to 200 nautical miles from a country's coast, where it controls fishing and resources |
| **MPA** | Marine Protected Area |
| **RFMO** | Regional Fisheries Management Organization; international groups managing shared stocks such as tuna |
| **IUU** | Illegal, Unreported, and Unregulated fishing |
| **Flag** | The country a ship is registered to (three-letter code, e.g. RUS) |
| **MMSI / SSVID** | The radio ID number of a ship |
| **Encounter** | Two ships staying close together at low speed for a while, away from port |
| **Carrier** | A cargo ship that collects catch from fishing boats and brings it to port |
| **Transshipment** | Moving catch from a fishing boat to a carrier at sea; often legal, a concern when it hides the catch's origin |
| **Apparent fishing effort** | Hours a vessel's movement looks like fishing (an estimate) |
| **4Wings** | GFW's map-data service, source of fishing effort and SAR detections |
| **API / token** | A way for code to request data from a service / the password-like key that identifies you |
| **DataFrame** | A table in Python (pandas) |
| **Antimeridian** | The 180 degree longitude line where map coordinates wrap from +180 to -180 |
| **Baseline** | The typical value to compare against, so an unusual number can be recognised |
